<Section number="02" title="Overview">

AKA is a fashion online shop: a catalogue of clothes, shoes and accessories from well-known brands, a product page with several photos, a cart and an admin area. I built it as a solo project at the end of 2022, with a Next.js front end and an Express server.

This is an early project, so there is no live demo, only screenshots. They come from a local run with a generated sample catalogue of 21 products, not from the original data. The shop page is plain Bootstrap, and the header logo is missing because some template assets were never committed. I show it as it was rather than redesigning it.

</Section>

<Section number="03" title="Under the hood">

A Next.js 13 front end (Pages Router, Bootstrap 5, axios) talking to an Express 4 server with Mongoose and MongoDB, bcrypt for password hashing and JWT for sessions. Products have a name, description, price, colours, sizes, a category and a brand, with three photos each.

To take the screenshots I ran a copy of the project against a local database in Docker. I did not change the application code.

**What I would improve.** Everything the screenshots do not show: tests, environment variables instead of values in code, and a design that does not depend on a template.

</Section>
